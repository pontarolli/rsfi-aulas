**1.** Antes de instalar os pontos de acesso em um prédio grande, a equipe técnica precisa identificar áreas de sombra de sinal, fontes de interferência e a melhor posição para cada equipamento. Qual etapa do projeto de rede sem fio corresponde a essa atividade?

- [ ] a) Comprar o maior número possível de pontos de acesso, sem qualquer planejamento prévio

- [ ] c) Instalar todos os pontos de acesso no mesmo cômodo, para simplificar a instalação
- [ ] d) O site survey é uma etapa desnecessária em qualquer projeto de rede sem fio
- [ ] e) Usar apenas um ponto de acesso, independentemente do tamanho do prédio

**2.** Para saber se um enlace ponto a ponto entre duas antenas vai funcionar, a equipe soma a potência de transmissão e os ganhos das antenas, e subtrai as perdas de cabo e de espaço livre no percurso, para verificar se o sinal chega acima da sensibilidade do receptor. Qual é o nome desse cálculo?

- [ ] a) Link budget é apenas o custo financeiro do projeto, sem relação com o sinal de rádio
- [ ] b) Link budget é o cálculo que soma ganhos (potência de transmissão, ganho de antenas) e subtrai perdas (cabos, espaço livre, obstáculos) para verificar se o sinal chega acima da sensibilidade do receptor
- [ ] c) Link budget não é necessário quando as antenas envolvidas são omnidirecionais
- [ ] d) Link budget serve apenas para o planejamento de redes cabeadas
- [ ] e) Basta instalar o equipamento mais caro disponível, sem nenhum cálculo prévio
